# Wiki Activity Log

Chronological append-only record of wiki operations. Each entry uses format: `## [YYYY-MM-DD] action | description`

Verbs: `ingest`, `create`, `update`, `move`, `delete`, `query`, `lint`, `setup`, `decision`. The description names the project folder it touched, so the last few entries answer "where was I?" without opening a page.

The first entry is written by setup. If this file has no entries, setup did not finish.
